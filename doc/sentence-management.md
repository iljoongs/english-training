# 문장 관리 — 주제별 예문 관리 화면

[메인 지시서](../CLAUDE.md)의 보조 문서. "문장 관리" 창의 요구사항과, 여기서 관리하는 예문(주제 + 본문 텍스트)이 읽기 창(학습 리딩 화면)과 어떻게 연결되는지를 다룬다. 개별 단어/표현의 해석·영작·표현 데이터 자체는 [공통 관리](common-management.md) §12(데이터 구조)를 참고한다.

---

## 1. 개요

앱의 **메인 윈도우는 읽기 창**(학습 리딩 화면, 마우스 오버 팝업 화면) 하나뿐이다. 읽기 창 자체에도 좌측에 주제 목록이 있어 주제를 클릭하면 바로 그 텍스트가 우측에 표시되며, 상단 **"관리" 메뉴 → "문장 관리"**를 클릭하면 주제를 추가·수정·삭제할 수 있는 문장 관리 창이 별도로 열린다. "관리" 메뉴에는 문장 관리 외에 해석/영작/표현 관리 항목도 있다([expression-management.md](expression-management.md) 참고).

문장 관리 창은 **멀티 윈도우**로 동작한다 — "관리 > 문장 관리"를 여러 번 누르면 여러 개가 동시에 떠 있을 수 있고, 그중 하나를 닫아도 다른 문장 관리 창이나 읽기 창(앱 전체)에는 영향이 없다. 다만 **메인 윈도우인 읽기 창을 닫으면 열려 있는 모든 문장 관리 창을 포함해 앱 전체가 종료된다.**

```text
앱 실행
   ↓
읽기 창 오픈 (메인, 좌: 주제 목록 / 우: 문장)
   ↓
좌측 목록에서 주제 클릭 → 우측 문장이 즉시 갱신
   ↓
"관리" 메뉴 → "문장 관리" 클릭
   ↓
문장 관리 창 오픈 (주제 추가/수정/삭제 전용)
   ↓
주제 더블클릭
   ↓
해당 주제의 텍스트로 읽기 창 갱신 (좌측 목록 선택도 함께 동기화)
```

---

## 2. 읽기 창의 화면 구성

```text
┌──────────────────────────────────────────────┐
│ 관리                                          │
├──────────────────────────────────────────────┤
│ [A-][A+]  ☑해석 ☐영작 ☐표현                  │
├───────────────┬──────────────────────────────┤
│ 일상 대화      │ I was wondering if you could  │
│ 비즈니스 영어  │ help me with this problem.    │
│ 여행 영어      │ I look forward to seeing you  │
│                │ soon.                         │
│                │                                │
└───────────────┴──────────────────────────────┘
```

"관리" 메뉴를 펼치면 문장 관리 / 해석 관리 / 영작 관리 / 표현 관리 네 항목이 있다([expression-management.md](expression-management.md) 참고).

* 왼쪽: 등록된 주제 목록(읽기 전용 탐색용, 단일 선택). 클릭하면 그 주제의 본문이 오른쪽에 즉시 표시된다.
* 오른쪽: 현재 선택된 주제의 본문 텍스트 — 마우스 오버 학습 팝업이 동작하는 영역([공통 관리](common-management.md) 참고).
* 주제를 추가·수정·삭제하려면 "관리 > 문장 관리" 메뉴로 별도 창을 연다(아래 §3).

---

## 3. 문장 관리 창의 화면 구성

```text
┌──────────────────────────────────────────────┐
│ 파일   문장                                   │
├──────────────────────────────────────────────┤
│ [신규 추가] [파일 추가] [삭제]                 │
├───────────────┬──────────────────────────────┤
│ 일상 대화      │ I was wondering if you could  │
│ 비즈니스 영어  │ help me with this problem.    │
│ 여행 영어      │ I look forward to seeing you  │
│                │ soon.                         │
│                │                                │
├───────────────┴──────────────────────────────┤
│ C:\Users\...\topics.json (286 B)              │
└──────────────────────────────────────────────┘
```

* 최상단: 메뉴(`파일`, `문장`) — 아래 §4.
* 그 아래: `신규 추가`, `파일 추가`, `삭제` 버튼.
* 왼쪽: 등록된 주제 목록. 여러 개를 동시에 선택할 수 있어야 한다(삭제용).
* 오른쪽: 현재 선택된 주제의 본문 텍스트를 표시/편집하는 영역. 텍스트를 직접 수정하면 해당 주제에 반영된다.
* 맨 아래: 현재 저장 파일의 **경로와 파일 크기**를 `경로 (크기)` 형식으로 표시하는 상태 표시줄. 주제를 추가/삭제/저장할 때마다 갱신된다.

---

## 4. 메뉴

### 4.1 파일

* **열기**: 다른 문장 관리 파일(`.json`)을 선택해 불러온다. 현재 목록은 그 파일 내용으로 교체되고, 이후 저장은 이 파일을 대상으로 한다.
* **저장**: 현재 주제 목록을 지금 열려 있는 파일에 저장한다(창을 닫거나 주제를 전환할 때도 자동으로 저장되지만, 메뉴로 즉시 저장할 수도 있다).
* **다른 이름으로 저장**: 현재 주제 목록을 새 경로의 `.json` 파일로 저장하고, 이후 저장 대상도 그 파일로 전환된다.

### 4.2 문장

* **신규**: 주제명을 입력받아 빈 주제를 추가한다 — 툴바의 `신규 추가` 버튼과 동일한 동작이다(아래 §5).
* **가져오기**: `.md` 파일을 선택해 새 주제로 추가한다 — 툴바의 `파일 추가` 버튼과 동일한 동작이다(아래 §6).
* **내보내기**: 왼쪽 목록에서 선택된 주제 하나를 `.md` 파일로 저장한다(§6의 md 형식과 동일하게 `# 제목` + 본문으로 기록). 선택된 주제가 없으면 안내 메시지를 표시한다.

---

## 5. 신규 추가

`신규 추가` 버튼을 클릭하면 주제명을 입력하는 대화상자가 나온다.

주제명을 입력하고 확인하면 빈 본문을 가진 새 주제가 목록에 추가되고 선택된 상태가 되며, 오른쪽 편집 영역에 텍스트를 입력할 수 있다.

---

## 6. 파일 추가 (가져오기)

`파일 추가` 버튼(또는 `문장 > 가져오기` 메뉴)을 클릭하면 파일 선택 대화상자가 열리고, 사용자가 `.md` 파일을 선택하면 그 내용을 읽어 새 주제로 추가한다.

### md 파일 형식 — 단일 주제

* 첫 줄의 `# 제목`을 주제명으로 사용한다.
* 그 이후의 본문 내용을 주제의 예문 텍스트로 사용한다.

샘플: [doc/sample-topic.md](sample-topic.md)

```markdown
# 일상 대화

I was wondering if you could help me with this problem. I look forward to seeing you soon.

You are supposed to be here by nine, but as far as I know the schedule has changed.
```

이 파일을 추가하면 "일상 대화"라는 주제가 목록에 생기고, 본문 텍스트가 그대로 예문으로 등록된다. `문장 > 내보내기`(§4.2)로 내보낸 파일도 같은 형식이므로 다시 가져올 수 있다.

### md 파일 형식 — 여러 주제(하루치 기사 모음)

파일 안에 `### 소제목`이 하나 이상 있으면, 각 `### ` 구간을 **별도의 주제로 각각** 추가한다(상단의 `# 날짜` 같은 최상위 제목은 파일을 구분하는 용도일 뿐 주제명으로는 쓰이지 않는다).

* `### 소제목` → 주제명(`Title`)
* 그 소제목부터 다음 `### ` 전까지의 내용 → 그 주제의 예문 텍스트
* 본문 중 `[링크 텍스트](URL)` 형태의 마크다운 링크는 URL을 제거하고 링크 텍스트만 남긴다(읽기 창은 순수 텍스트만 표시하므로).
* 빈 줄이 여러 번 이어져도 문단 구분을 위한 빈 줄 하나로 정리된다.

샘플(하루치 뉴스 기사 모음): `data/2026-08-22.md`

```markdown
# 2026-08-22

### Buckingham Palace

Prince Harry is not allowed to stay at Buckingham Palace ... [News reports](https://example.com) say ...

### Influencers

Many people want to take the perfect  [photograph](https://example.com). Influencers try hard to do this. ...

### Photos of the Sun

Astronomers have taken the best-ever photos of the Sun. ...
```

이 파일을 추가하면 "Buckingham Palace", "Influencers", "Photos of the Sun" 세 개의 주제가 한 번에 목록에 생긴다.

## 7. 삭제

왼쪽 목록에서 주제를 선택(다중 선택 가능)하고 `삭제` 버튼을 클릭하면 선택된 주제(들)가 삭제된다.

## 8. 읽기 창과의 연결

* **읽기 창 → 문장 관리 창**: 읽기 창 상단 "관리 > 문장 관리" 메뉴를 클릭하면 문장 관리 창이 새로 열리고, 자신을 연 읽기 창(=메인 윈도우)을 기억한다. 문장 관리 창이 닫힐 때 읽기 창의 좌측 주제 목록도 최신 상태로 갱신된다.
* **문장 관리 창 → 읽기 창**: 왼쪽 목록에서 주제를 더블클릭하면 **새 창을 열지 않고**, 읽기 창의 내용(제목·본문·좌측 목록 선택)이 그 주제로 교체된다. 마우스가 텍스트 위에 있던 상태였다면 열려 있던 팝업은 갱신 전에 닫힌다.
* **읽기 창 자체의 좌측 목록**에서 주제를 클릭해도(더블클릭 아님) 동일하게 즉시 갱신된다 — 문장 관리 창을 열지 않고도 등록된 주제 사이를 빠르게 전환할 수 있다.
* 읽기 창에서 사용하는 학습 표현 데이터(해석/영작/표현)는 주제와 무관하게 **전체 공통**으로 관리한다([공통 관리](common-management.md) §12, §26.2). 즉 어떤 주제의 텍스트든 동일한 표현 사전을 기준으로 매칭한다.
* "관리 > 문장 관리"를 여러 번 누르면 문장 관리 창이 여러 개 뜰 수 있다 — 어느 문장 관리 창에서 더블클릭해도 결국 갱신 대상은 동일한 하나의 읽기 창이다. 문장 관리 창은 개별적으로 닫아도 앱에 영향이 없지만, **읽기 창(메인 윈도우)을 닫으면 열려 있는 문장 관리 창을 포함해 앱 전체가 종료**된다.

---

## 9. 예문(본문 텍스트) 표시 요구사항

읽기 창에 표시되는 텍스트 자체에 대한 요구사항은 다음과 같다 (문장 관리에서 입력한 본문 텍스트가 그대로 사용됨).

* 여러 문장을 연속해서 표시할 수 있어야 한다.
* 문단 단위의 텍스트도 표시할 수 있어야 한다.
* 텍스트의 가독성을 고려하여 적절한 줄 간격과 문장 간격을 제공한다.

예문에 등장하는 단어/표현 중 학습 팝업을 띄우고 싶은 대상은 [공통 관리](common-management.md) §12의 `LearningExpression` 데이터에 먼저 등록되어 있어야 한다. 등록되지 않은 단어는 팝업 없이 그냥 텍스트로만 보인다(공통 관리 §15). 대소문자·구두점은 매칭 시 정규화되므로(공통 관리 §26.4) 예문 안에서는 자연스러운 문장 그대로 작성하면 되지만, 어형 변화(`looked forward to` 등)는 자동으로 인식되지 않으므로 활용형을 쓸 경우 그 활용형 자체를 학습 데이터에 별도로 등록해야 한다.
